# Anime · アニメ

Мобильное веб-приложение (PWA) для просмотра аниме: каталог, мгновенный поиск,
профиль со статистикой, просмотр вместе и встроенный плеер Kodik.
Работает как обычный сайт и устанавливается на телефон с домашнего экрана.

## Возможности

### Каталог
- Подборки «Популярное», «Онгоинги», «Свежее», «Топ рейтинга», «Случайное».
- Фильтр по 34 жанрам, работает совместно с любой подборкой.
- Бесконечная прокрутка, скелетоны, кеш подборок на 15 минут.
- Ряд «Продолжить смотреть» с сохранённой позицией.

### Поиск
- Мгновенный: локальный индекс отвечает сразу, каталог Kodik догружается следом.
- **Опечатки** — «натаруто» → «наруто» (Левенштейн по словарю названий).
- **Раскладка** — `yfhenj` → «наруто».
- **Синонимы** — «титаны» → «Атака титанов», «ван пис» → «One Piece»,
  «клинок рассекающий демонов» → «Истребитель демонов» (около 35 групп).
- **Голосовой поиск** — кнопка микрофона (Web Speech API, `ru-RU`).
- Пересортировка выдачи по релевантности: Kodik любит подмешивать «похожее»,
  такие карточки отсекаются.

### Плеер
- Встроенный список озвучек и качества Kodik — свой список не дублируется.
- Улучшение картинки: `filter: contrast(1.05) saturate(1.1)` (отключается в настройках).
- **Пропуск опенинга** — автоперемотка на 1:30 (настраивается: 1:00 / 1:15 / 1:30 / 1:45)
  плюс ручная кнопка. Работает через `postMessage` к плееру.
- **Продолжить с места** — позиция сохраняется, при возврате предлагается
  «Вы остановились на 10:00 · серия 3» и кнопка «С начала».
- Полноэкранный режим, ссылки на Shikimori и MAL, «открыть в новой вкладке».
- **Связанные тайтлы** под описанием: другие сезоны, фильмы, OVA и спешлы одной франшизы.
  Подписи «Продолжение», «Приквел», «Спин-офф», «Пересказ» берутся из графа связей
  **AniList**, сами релизы и озвучки — из Kodik. Карточка открывает нужный тайтл в плеере.

### Профиль
- Имя и аватар (цвет выводится из имени).
- Ранги: Новичок → Зритель → Отаку → Сэмпай → Легенда → Хранитель (0/5/20/50/120/300 ч).
- Статистика: часы, тайтлы, серии, дни; любимые жанры.
- 10 достижений (первый кадр, сотка серий, ночной зритель, без опенинга и т. д.).
- Списки: Смотрю / В планах / Просмотрено / Брошено, избранное, история.

### Смотреть вместе (Watch Party)
- Комната на 5-символьный код, ссылка-приглашение `?party=КОД`.
- Общий чат и синхронизация: хост ведёт — пауза, перемотка и время повторяются у гостей
  (расхождение больше 7 секунд выравнивается автоматически).
- Открытый хостом тайтл автоматически открывается у всех.
- **Смена серии** повторяется у гостей: хост переключает серию в плеере — плеер гостя
  перезагружается на неё же (`?episode=N`) с той же озвучкой и позицией.
- Опоздавший сразу видит открытый тайтл, серию, время и последние 20 сообщений чата
  (с сервером; на `ntfy.sh` — только текущее состояние).
- Транспорт — публичный канал `ntfy.sh` (POST + SSE), бэкенд не нужен.
  Если поднят свой сервер (см. «Свой бэкенд»), комната переезжает на WebSocket,
  а в окне комнаты появляется пометка «· сервер».

### Синхронизация списков
- **Вход в один клик** через Shikimori или MyAnimeList, если поднят свой сервер
  (см. «Свой бэкенд»): статусы и число просмотренных серий подтягиваются сами,
  тайтлы находятся в каталоге по `shikimori_id` или по названию.
- Списки обновляются кнопкой «Обновить списки» и сами — если прошло больше 6 часов.
- Без сервера остаётся импорт XML-экспорта **Shikimori** или **MyAnimeList**
  (оба отдают формат `<myanimelist><anime>`): статусы и число серий переносятся
  в локальные списки, названия сопоставляются с каталогом Kodik.
- Файл разбирается в браузере и никуда не отправляется.
- Экспорт всех данных в JSON и полный сброс — в настройках.

### Перенос профиля
- «Сохранить в облако» → сервер отдаёт короткий код из 7 символов.
- На другом устройстве «Загрузить по коду» — и списки, история, прогресс и
  настройки оказываются на месте. Код живёт 30 дней, кеш каталога не переносится.
- Работает только со своим сервером; без него остаётся экспорт в файл.

## Запуск локально

Любой статический сервер из папки проекта, например:

```bash
python -m http.server 8000
# или
npx serve
```

Открыть `http://localhost:8000`.

> Открытие через `file://` работать не будет: нужны `http(s)` для fetch, Service Worker и manifest.

## Деплой (GitHub Pages)

1. Положить `index.html`, `app.css`, `app.js`, `sw.js`, `manifest.json`, `icon.png`, `icon-192.png`
   в корень репозитория (или в ветку `gh-pages`).
2. Settings → Pages → Source: Deploy from a branch → `main` / `root`.
3. Открыть `https://<username>.github.io/<repo>/`.

Все пути относительные, поэтому сайт работает и из подпапки.

## Свой бэкенд (необязательно)

В папке `server/` лежит отдельный бинарь на Rust (`axum`) — прокси Kodik и
WebSocket-комнаты. Публикуемый сайт в нём не нуждается: без сервера всё работает
как раньше, просто запросы идут напрямую в Kodik и `ntfy.sh`.

Что даёт сервер:

- **Токены Kodik не видны в браузере** и меняются на сервере при ошибке.
- **Меньше трафика**: ответ обрезается (490 КБ → 89 КБ) и сжимается brotli
  (10–18 КБ по проводу), плюс общий кеш на всех посетителей.
- **Watch Party через WebSocket** на своём домене вместо публичного `ntfy.sh`;
  опоздавший сразу получает тайтл, серию, время и историю чата.
- **Вход через Shikimori/MAL в один клик**: `client_secret` остаётся на сервере,
  браузер получает только непрозрачный `sid`.
- **Перенос профиля по коду** между устройствами.
- Скорость видео не меняется: плеер Kodik грузится в iframe с их CDN,
  бэкенд отдаёт только JSON.

Как включить:

```js
// один раз в консоли сайта
localStorage.setItem('anime_api', 'https://api.example.com');
location.reload();
```

или вписать адрес в `API_BASE` в начале `app.js` — тогда бэкенд включён у всех.
Запросы обёрнуты в проверку `/api/health`: если сервер молчит, каждый вызов
тихо уходит напрямую в Kodik, а комната через 3 попытки переезжает на `ntfy.sh`.

Сборка и настройка (systemd, nginx/Caddy, HTTPS, WS-заголовки) — в `server/README.md`
в репозитории проекта. В архив с сайтом сервер не входит: это отдельный бинарь.

## Структура

```
index.html        — разметка: экраны, плеер, шторки, шаблоны

```

## Источник данных

Каталог и ссылки на видео — публичный API **Kodik** (`https://kodik-api.com`).
Он отдаёт `Access-Control-Allow-Origin: *`, поэтому запросы идут напрямую из браузера,
без CORS-прокси. Постеры и описания приходят из `material_data`.

Токены доступа хранятся в `app.js` в закодированном виде (`ENC_TOKENS`):
при загрузке они расшифровываются, невалидные отбрасываются, а при ошибке одного
из них приложение автоматически пробует следующий.

Плеер — официальный iframe `kodikplayer.com`. Управление идёт через
`postMessage({ key: 'kodik_player_api', value: { method, ... } })`:
поддерживаются `play`, `pause`, `seek`, `volume`, `speed`, `mute`, `unmute`,
`enter_pip`, `exit_pip`. Обратно плеер присылает `kodik_player_time_update`,
`duration_update`, `video_started`, `video_ended`, `current_episode`, `play`, `pause`.

Серия выбирается параметром `?episode=N` в адресе плеера — другого способа переключения
у iframe нет, поэтому смена серии в комнате делает перезагрузку плеера гостя.

Связанные тайтлы: связи и их типы — публичный GraphQL **AniList**
(`https://graphql.anilist.co`), релизы и озвучки — поиск Kodik по оригинальному названию.
Если AniList недоступен, блок всё равно строится — с подписями по формату и году.

## Ограничения

- **Watch Party без своего бэкенда идёт через публичный `ntfy.sh`** — не передавайте
  в чат личные данные, сообщения видят все, кто знает код комнаты. Со своим сервером
  (`localStorage.anime_api`) комната живёт на вашем домене.
- Смена серии в комнате требует, чтобы Kodik-плеер открылся у гостя: если iframe
  заблокирован (VPN, блокировщик), переключение не произойдёт.
- **Любимые персонажи** требуют API персонажей, которого у Kodik нет —
  вместо них показываются любимые жанры и тайтлы.
- Вход через Shikimori/MAL и перенос профиля по коду работают только со своим
  сервером: приложению нужен `client_secret` и место, где хранить сессии.
- Доступность конкретных тайтлов зависит от Kodik.
