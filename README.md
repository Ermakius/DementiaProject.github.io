# Anime · アニメ

Мобильное веб-приложение (PWA) для просмотра аниме: каталог, поиск, озвучки и плеер.
Работает как обычный сайт и устанавливается на телефон с домашнего экрана.

## Возможности

- **Главная** — подборки «Популярное», «Онгоинги», «Свежее», «Топ рейтинга», «Случайное».
- **Жанры** — фильтр по 34 жанрам, работает совместно с любой подборкой.
- **Поиск** — по русскому и оригинальному названию, с бесконечной прокруткой.
- **Карточка и плеер** — постер, рейтинг, год, число серий, описание, жанры,
  выбор озвучки и качества, полноэкранный режим, ссылка «открыть в новой вкладке».
- **Продолжить смотреть** — последние просмотренные тайтлы на главной.
- **Избранное** — вкладка «Моё», сердечко в плеере.
- **Офлайн** — оболочка и постеры кешируются Service Worker'ом,
  подборки — в localStorage, поэтому приложение открывается и без сети.

## Запуск локально

Любой статический сервер из папки проекта, например:

```bash
python -m http.server 8000
# или
npx serve
```

Открыть `http://localhost:8000`.

> Открытие через `file://` работать не будет: нужны `http(s)` для fetch, Service Worker и manifest.

## Деплой (GitHub Pages)

1. Положить `index.html`, `sw.js`, `manifest.json`, `icon.png`, `icon-192.png` в корень репозитория
   (или в ветку `gh-pages`).
2. Settings → Pages → Source: Deploy from a branch → `main` / `root`.
3. Открыть `https://<username>.github.io/<repo>/`.

Все пути относительные, поэтому сайт работает и из подпапки.

## Структура

```
index.html        — всё приложение: разметка, стили, логика
manifest.json     — PWA-манифест
sw.js             — Service Worker: оболочка (network-first) + постеры (cache-first)
icon.png          — иконка 512×512
icon-192.png      — иконка 192×192
```

## Источник данных

Каталог и ссылки на видео — публичный API **Kodik** (`https://kodik-api.com`).
Он отдаёт `Access-Control-Allow-Origin: *`, поэтому запросы идут напрямую из браузера,
без CORS-прокси. Постеры и описания приходят из `material_data`.

Токены доступа хранятся в `index.html` в закодированном виде (`ENC_TOKENS`):
при загрузке они расшифровываются, невалидные отбрасываются, а при ошибке одного
из них приложение автоматически пробует следующий.

Плеер — официальный iframe `kodikplayer.com`.

## Что было починено

- **Каталог не загружался.** Все запросы шли через сторонние CORS-прокси,
  которые больше не работают (`api.allorigins.win` → 500, `corsproxy.io` → 401,
  `api.codetabs.com` → таймаут). Теперь Kodik вызывается напрямую.
- **В сетке было 1–2 карточки.** Kodik отдаёт отдельную строку на каждую озвучку,
  поэтому 30 строк — это 2–3 тайтла. Добавлены группировка по `shikimori_id`,
  сбор озвучек в один тайтл и постраничная догрузка до нужного количества карточек.
- **Битый токен** (первый в списке) ронял инициализацию — добавлена валидация
  после расшифровки и ротация токенов.
- **Гонки при быстром переключении подборок**: скелетон мог остаться навсегда.
  Переписана логика загрузки через номер запроса.
- **Не применялся раздел**: обработчик чипов не сохранял выбранную секцию.
- **Секции выглядели как голый текст** — у кнопок не было класса `.chip`.
- **Кеш секции терял курсор пагинации**, из-за чего «Ещё» показывало дубли.
- **История/избранное**: добавлены вкладка «Моё», ряд «Продолжить смотреть»,
  сохранение прогресса и повторная загрузка озвучек для старых записей.
- **Плеер**: скрыт встроенный список озвучек (`?translations=false`),
  добавлены выбор перевода/качества, повторный запуск, полноэкранный режим,
  подсказка и ссылка «открыть в новой вкладке» на случай блокировки iframe.
- **Manifest** был blob-URL (установка PWA не работала) — теперь отдельный `manifest.json`
  с иконками 192 и 512.
- **Service Worker** кешировал ответы API как картинки и не чистил старые версии —
  переписан: оболочка network-first, только изображения cache-first, версии удаляются.
- **Доступность**: исправлен контраст текста и подписей, убран запрет масштабирования.
  Lighthouse: accessibility / best practices / SEO — 100.

## Примечание

Приложение не хранит видео у себя, а только встраивает плеер Kodik.
Доступность конкретных тайтлов зависит от этого сервиса.
